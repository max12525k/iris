# Iris's learning journal

A chronological record of every package Iris has learned, why it was needed,
and what task triggered the learning. Append-only — entries here are never
edited, only added. Useful for:

- Spotting recurring needs that should graduate from "installed once" to
  "make this a first-class skill or tool wrapper".
- Reviewing whether Iris is reaching for the right ecosystem (e.g., shelling
  out to a CLI when a Python lib would be cleaner, or vice versa).
- Understanding *why* a package is in the manifest months later.

## Format

```
## YYYY-MM-DDTHH:MM:SSZ — <ecosystem> <package>
**Trigger:** <one sentence on what task created the need>
```
